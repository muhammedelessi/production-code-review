# Source Basis

This skill is an original review workflow informed by public, high-authority engineering guidance. It does not copy an upstream code-review skill wholesale.

Primary source families:

- OpenAI official `openai/skills` — `security-best-practices`
- Microsoft official `microsoft/skills` — `code-review.prompt.md`
- React official documentation — Rules of React, Keeping Components Pure, performance guidance
- TypeScript official documentation — `strict`, `noImplicitAny`, and related compiler checks
- Flutter official documentation — Performance Best Practices and rendering-performance guidance
- Dart official documentation — Effective Dart
- OWASP — Top 10:2025 and Developer Guide

Use current project documentation and framework documentation when a review depends on version-specific behavior. Do not treat this reference list as a substitute for verifying changing APIs or framework semantics.
